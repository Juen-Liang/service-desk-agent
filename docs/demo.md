# 4 个演示脚本

## 1. 无须审批的账号解锁

管理员进入演示业务系统，选择林小雨，应用“登录失败锁定”。员工提交账号解锁工单并运行模拟流程。展示查询工具、后端策略、操作回执和解锁后的状态；员工确认关闭。

## 2. 审批后开通临时权限

员工提交 DEV_READONLY，期限 24 小时，用途为开发联调。开始分析后展示“待审批”，此时业务系统没有新增权限。审批人员检查目标和期限后批准；员工看到自动继续、授权回执和结果核验。可在待审批时重启服务，证明检查点可继续。

## 3. 软件授权与边界

员工申请 IDE_PRO，说明开发用途。批准后核验本人授权和剩余名额。在评测报告打开“无剩余名额”样例，展示该任务使用独立库存、执行时拒绝超发并转人工。并发最后一个名额由真实数据库测试验证，不通过手工改报告演示。

## 4. 设备报障与人工接管

员工描述笔记本无法启动。Agent 查本人设备与制度，转 IT 人员。处理人员接管后记录“检查电源并更换线缆”，进入待确认；员工确认关闭或反馈未解决重新打开。

## 招聘演示重点

先说明独立演示系统的边界，再演示业务闭环。重点解释：模型负责理解和查询，后端负责授权；审批绑定具体参数；检查点负责流程恢复，业务回执负责避免重复执行；评测检查数据库最终状态。未接真实模型时使用“模拟流程”，不能把它称为真实模型效果。
